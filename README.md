### 🚀 Final 2-Minute Activation

#### 1. Enable Live GitHub Pages (Instant Web Link)
1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment → Branch**, select **`main`** and **`/ (root)`**.
3. Click **Save**. Your site is instantly live at: `https://vikasgadade5sep-oss.github.io/ai-pulse/`!

#### 2. Add the 4-Day Automated Workflow
1. Click **Add file → Create new file**.
2. Set file name to: `.github/workflows/ai_pulse.yml`.
3. Paste the contents of `.github/workflows/ai_pulse.yml` and click **Commit changes**.

#### 3. Add Free Gemini API Key (For Fresh Updates)
1. Get your free key from [aistudio.google.com](https://aistudio.google.com).
2. Go to **Settings → Secrets and variables → Actions**.
3. Add repository secret `GEMINI_API_KEY`.
